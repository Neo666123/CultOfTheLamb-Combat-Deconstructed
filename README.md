# 《咩咩启示录》战斗手感解构与 2.5D 控制器工程 (Cult of the Lamb Combat Deconstructed)

本项目是专为独立游戏《生物改造与深渊探索》（小黑猫太空探索）打造的**极简白盒战斗手感研究工程**。  
全工程基于 **Unity 6 (6000.x)** 重构，彻底剔除了老旧冗余包与黑盒投影脚本，完全还原了《咩咩启示录》(Cult of the Lamb) 拳拳到肉的纯正打击感。

---

## 🌟 核心功能一览

1. **8向移动与高速冲刺**：基于 Unity 6 原生 linearVelocity，零惯性启动与刹车，带 0.2s 冲刺无敌帧；
2. **三段挥剑连击状态机**：原汁原味的三段连招推近与后摇取消；
3. **程序化半月剑气 (Sword Swipe)**：动态生成扇形斩击网格与伤害判定；
4. **打击感四件套 (Juice System)**：0.08s 顿帧 (HitStop) + 受击白闪 + 阻尼击退 + 镜头微震；
5. **0.15s 宽松弹反系统 (Parry)**：低门槛见招拆招机制；
6. **2.5D 广告牌相机与 Y-Sort 排序**：所见即所得的正规 2.5D 舞台，Scene 视图与 Game 视图 100% 对齐。
